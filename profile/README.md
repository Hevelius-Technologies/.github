Hevelius is a modular spatial platform for geospatial data exploration and decision support. Each domain is a module built on one shared map foundation.

It's named after Johannes Hevelius, the 17th-century astronomer who mapped the Moon.

Hevelius is at the foundation stage, and its code is private for now.
